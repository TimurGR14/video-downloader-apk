# Видео Загрузчик для Android

Скачивает видео в MP4 по ссылке (VK, TikTok, YouTube, Rutube, Instagram и 1800+ сайтов). Работает на открытых [yt-dlp](https://github.com/yt-dlp/yt-dlp) и [youtubedl-android](https://github.com/JunkFood02/youtubedl-android).

**Скачать:** [VideoDownloader-Android.apk](https://github.com/TimurGR14/video-downloader-apk/releases/latest/download/VideoDownloader-Android.apk)

Для старых 32-битных телефонов: [VideoDownloader-Android-old-phones.apk](https://github.com/TimurGR14/video-downloader-apk/releases/latest/download/VideoDownloader-Android-old-phones.apk)
